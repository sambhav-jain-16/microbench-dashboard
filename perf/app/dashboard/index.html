Each graph displays benchmark results relative to its baseline commit, which is usually the latest stable release at the time of testing. The 95% confidence interval is displayed in light gray. On hover, the graph displays the benchmarked commit at that point (click to view full commit).

Note that some commits are not tested, so there could be multiple commits (not shown) between two points on the graph.

Using the 'unit' search box above leads to a page that shows much more detail about each individual point in the selected time range. Another way of reaching this page is to click the unit name that acts as each graph's title, i.e. "sec/op".

Baseline Comparison: You can compare metrics against a historical baseline by adjusting the "Baseline" field (default: 45 days). When a baseline is set, each data point is compared to the same metric from the baseline period. The dashboard calculates this comparison locally—baseline is not a label in VictoriaMetrics but rather a way to compare current metrics against historical data. With Duration=90 and Baseline=45, each data point will be compared to its value from 45 days before the start of the 90-day window. Positive values indicate regressions, negative values indicate improvements. This is particularly useful for identifying performance trends over time.
